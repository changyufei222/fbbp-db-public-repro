# Code release status

This public release contains the analysis code located for the packaged workflows:

- `code/strict_background/`: strict combined AIR/ALL background analysis scripts.
- `code/air_all_background/`: AIR/ALL comparison scripts.
- `code/binding_interface/`: binding-window/interface analysis scripts.
- `code/website_bundle/`: static website data-bundle build script.
- `ml_release/source_scripts/`: source scripts for frozen binder-only, target-aware, loop-aware, and derived split construction.
- `scripts/validate_release.py`: table-count, root-manifest, checksum, and private-file validation.

This repository is the public Briefings in Bioinformatics data and reproducibility release. It includes the release tables, selected analysis outputs, run documentation, the complete frozen ML release, test data, expected outputs, and source code. The frozen release DOI is `10.5281/zenodo.24361542`; the concept DOI `10.5281/zenodo.20626952` points to the latest release.
