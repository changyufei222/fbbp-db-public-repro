# Supplementary Data 5

Version: v20261119

This folder contains selected machine-readable source data needed to verify the extended summaries, source tables, and figure panels referenced in the Supplementary Information.

- `Revision_Source_Tables/`: source tables for Supplementary Tables S18-S20 and source data for Supplementary Figures S12-S14.
- `Key_Result_Summaries/`: compact summary statistics supporting Tables S13 and S15-S17, including clustered inference, G240 candidate recovery, and boundary reproducibility.

The full executable analysis pipeline, raw intermediate outputs, complete frozen database release, and machine-learning package are available through the public repository release and its versioned archive.

`MANIFEST_SHA256.csv` lists the byte count and SHA-256 checksum of every file in this folder except the manifest itself. The manifest is regenerated after all final text and metadata edits.
